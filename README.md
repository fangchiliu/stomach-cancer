# stomach-cancer

Multi-omics analysis of stomach adenocarcinoma (TCGA-STAD, GSE66229, and a
gastric single-cell atlas), converging on **INHBA** as a validated,
survival-associated target.

The analysis lives in **[`repo_submission/`](repo_submission/)** as a set of
numbered R scripts — see that folder's
[README](repo_submission/README.md) for the pipeline overview, method notes,
and how to run it.
